# Lesson 205: Copy a variadic argument cursor

Original chibicc commit: [`603de502fd8bad750d48aaf9a66c547e5ca04c2a`](https://github.com/rui314/chibicc/commit/603de502fd8bad750d48aaf9a66c547e5ca04c2a).
Earlier explanations are available in Git history.

The bundled header adds va_copy(dest, src), implemented as assignment of the
single __va_elem structure in each one-element va_list array. Each list then
advances its own offsets and overflow pointer independently; both refer to the
same saved argument values. Existing aggregate assignment already emits the
required byte copy, so this commit needs no new compiler machinery.

```sh
printf '#include <stdarg.h>\nint f(int n,...){va_list a,b;va_start(a,n);va_copy(b,a);return va_arg(a,int)+va_arg(b,int);}int main(void){return f(1,21);}\n' > /tmp/lesson.c
python3 python/main.py -S -o /tmp/lesson.s /tmp/lesson.c
gcc -o /tmp/lesson /tmp/lesson.s
/tmp/lesson
echo $?  # 42
```

Generated byte moves copy the cursor structure. Both reads obtain 21, and
addition leaves 42 in rax. Tests verify independent register cursors, copying
an already advanced stack cursor, and the original formatting example. Python
keeps the historical header verbatim; va_end remains an empty macro.

## Tests and attribution

Run from the repository root on x86-64 Linux/WSL with Python 3 and GCC
(`build-essential` on Ubuntu):

```sh
python3 python/test.py
```

The tests check emitted assembly and assemble/link/run real executables;
temporary artifacts are cleaned up and execution has a timeout.
Python builds syntax trees and emits assembly; it does not use `eval()`
or invoke the original compiler. Python lists, dataclasses, tuples, and
`None` replace C linked lists, structs, output pointers, and null pointers.
Unicode whitespace and character-based diagnostic positions are intentional
Python differences. Any further differences for this step are described above.
